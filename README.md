# Gadget Store
[DEMO LINK](https://frontend-i9xqged7v-five-ends.vercel.app/#/)

A modern e-commerce frontend application built with React and TypeScript. The project was developed as a team project to practice modern frontend development, component-based architecture, state management, and collaborative work with Git and GitHub.

## Tech Stack

### Core

- **React 19** — building interactive user interfaces using reusable components.
- **TypeScript 6** — static typing for better code reliability and maintainability.
- **Vite 8** — fast development server and production build tool.
- **React Router 7** — client-side routing and navigation between pages.

### State Management & Backend
- **Zustand** — lightweight state management for sharing application state between components.
- **Supabase** — backend platform used for database and application data integration.

### Code Quality & Development Tools
- **ESLint** — code quality and error checking.
- **Prettier** — automatic code formatting.
- **Stylelint** — CSS and stylesheet linting.
- **TypeScript Compiler** — static type checking.

### Architecture

- The project follows the Atomic Design methodology to organize UI components into reusable and maintainable building blocks.

## Getting Started

### Prerequisites

Make sure you have installed:
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/TeoKisel/gadget-store.git
   ```

2. Navigate to the project directory:

   ```bash
   cd gadget-store
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

Recommended build settings:

- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`

Make sure to configure the required environment variables in the Vercel project settings.
